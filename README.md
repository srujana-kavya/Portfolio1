# Modern Portfolio Website

A stunning, responsive personal portfolio built with React, Tailwind CSS, and Framer Motion. Featuring a futuristic dark theme, glassmorphism effects, and smooth animations.

## 🚀 Features

- **Modern UI/UX**: Futuristic dark theme with glassmorphism.
- **Responsive Design**: Optimized for all screen sizes.
- **Smooth Animations**: Powered by Framer Motion for a premium feel.
- **Interactive Background**: Particle effects for an immersive experience.
- **SEO Optimized**: Built with semantic HTML and meta tags.

## 🛠️ Tech Stack

- **Framework**: React 19
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React & React Icons

## 📦 Deployment

### Deploy to Vercel

The easiest way to deploy this project is to use the [Vercel Platform](https://vercel.com/new).

1. Push your code to a GitHub repository.
2. Import the project into Vercel.
3. Vercel will automatically detect the Vite configuration.
4. Click **Deploy**.

The project includes a `vercel.json` file to handle client-side routing and clean URLs automatically.

## 🛠️ Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
